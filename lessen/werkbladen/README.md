# Invulbare werkbladen

Zelfstandige HTML-blokken (geen externe bestanden) voor in Systeme.io, element **Onbewerkte HTML**:

- `werkblad-financiele-check.html`: werkblad module 2, rekent totalen, buffer en wat je overhoudt automatisch uit.
- `sjabloon-beleggingsplan.html`: beleggingsplan module 5.

Antwoorden worden automatisch bewaard in de browser van de cursist (localStorage), dus alleen op dat apparaat en in die browser. Met de knop "Opslaan als PDF of printen" bewaart de cursist een eigen kopie. De printbare versies staan als Markdown in `lessen/module-2/` en `lessen/module-5/`.

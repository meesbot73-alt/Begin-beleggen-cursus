# Meerkeuzetests module 1

Eén zelfstandig HTML-blok per les (geen externe bestanden). In Systeme.io staat elke test als aparte les ("Test jezelf: les 1.x") direct na de les, in een element **Onbewerkte HTML**.

Let op bij plakken in Systeme.io: het HTML-blok groeit daar niet vanzelf mee, waardoor score en "Opnieuw proberen" onderaan wegvallen. In Systeme.io is daarom een klein script toegevoegd dat de hoogte van het blok aanpast. Dat script staat niet in deze bestanden; neem het mee als je een test opnieuw plaatst of er een nieuwe maakt.

Systeme.io heeft zelf alleen een quiz per module, niet per les.

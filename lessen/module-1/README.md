# Module 1: Waarom beleggen?

In deze module ontdek je waarom geld op een spaarrekening langzaam minder waard wordt, en hoe beleggen je helpt om dat te voorkomen. Je hoeft nog niets te kopen. Het gaat eerst om het waarom.

Deze module is gratis, zodat je kunt proeven hoe de cursus werkt.

| Les | Onderwerp | Leestijd |
| --- | --- | --- |
| [1.1](les-1-1-sparen-versus-beleggen.md) | Sparen versus beleggen | 5 min |
| [1.2](les-1-2-inflatie.md) | Inflatie: waarom geld op de bank minder waard wordt | 5 min |
| [1.3](les-1-3-rente-op-rente.md) | Het effect van rente-op-rente en tijd | 6 min |

Na deze module kun je:

- uitleggen wat het verschil is tussen sparen en beleggen;
- vertellen wat inflatie met je spaargeld doet;
- laten zien waarom vroeg beginnen zoveel uitmaakt.

> Alle voorbeelden in deze cursus zijn bedoeld als uitleg. Het is geen persoonlijk financieel advies. Beleggen brengt risico's met zich mee: je kunt (een deel van) je inleg verliezen.

# Begrippenlijst: alle afkortingen en termen op een rij

Kom je in de cursus, bij je broker of in een factsheet een afkorting tegen die je niet kent? Hier staat hij, voluit en in gewone taal. Tussen haakjes staat de les waar je er meer over leest.

## Afkortingen

| Afkorting | Voluit | Wat betekent het? |
| --- | --- | --- |
| Acc | *Accumulating* (accumulerend) | Het fonds herbelegt het dividend automatisch (3.3) |
| ACWI | *All Country World Index* | Wereldindex van MSCI met ontwikkelde én opkomende landen (3.3) |
| AEX | *Amsterdam Exchange index* | De 30 grootste bedrijven op de beurs van Amsterdam (3.3, 3.4) |
| AFM | Autoriteit Financiële Markten | Nederlandse toezichthouder die let op eerlijk gedrag van financiële bedrijven (4.1, 6.2) |
| AOW | Algemene Ouderdomswet | Het basispensioen van de overheid (2.3) |
| BaFin | *Bundesanstalt für Finanzdienstleistungsaufsicht* | De Duitse toezichthouder, onder meer voor DEGIRO en Trade Republic (4.1) |
| BSN | Burgerservicenummer | Je persoonlijke nummer bij de overheid; nodig om een rekening te openen (4.2) |
| CBS | Centraal Bureau voor de Statistiek | Meet onder meer de inflatie in Nederland (1.2) |
| CySEC | *Cyprus Securities and Exchange Commission* | De toezichthouder van Cyprus, onder meer voor MEXEM (bijlage module 4) |
| Dist | *Distributing* (distribuerend) | Het fonds keert het dividend uit op je rekening (3.3) |
| DNB | De Nederlandsche Bank | Nederlandse toezichthouder op de financiële gezondheid van banken en brokers (4.1, 6.2) |
| DUO | Dienst Uitvoering Onderwijs | Regelt onder meer studiefinanciering en studieschuld (2.1) |
| ECB | Europese Centrale Bank | Bewaakt de inflatie in de eurozone en houdt toezicht op grote banken (1.2, 6.2) |
| EID | Essentiële-informatiedocument | Nederlandse naam voor het KID (3.3) |
| ETF | *Exchange Traded Fund* | Beursverhandeld fonds: een mandje beleggingen dat je op de beurs koopt en verkoopt, net als een aandeel (1.1, 3.3) |
| EUR / USD | Euro / Amerikaanse dollar | Valutacodes. Kies bij voorkeur een notering in EUR om wisselkosten te vermijden (3.3, 3.5) |
| FOMO | *Fear Of Missing Out* | De angst om iets mis te lopen; leidt tot impulsaankopen (5.2) |
| FTSE | *Financial Times Stock Exchange* | Brits indexbedrijf (FTSE Russell), bekend van de FTSE All-World (3.3) |
| GAK | Gemiddelde aankoopkoers | Wat je gemiddeld per stuk hebt betaald (4.3) |
| IMI | *Investable Market Index* | Een index waarin ook kleinere bedrijven zitten (bijlage module 3) |
| IPO | *Initial Public Offering* | Beursgang: een bedrijf biedt voor het eerst aandelen aan op de beurs (3.1) |
| ISIN | *International Securities Identification Number* | Wereldwijd unieke code van 12 tekens voor een aandeel of fonds. Begint met de landcode, bijvoorbeeld IE (Ierland) of NL (3.1, 3.3) |
| K/W | Koers-winstverhouding | Koers gedeeld door de winst per aandeel (3.1) |
| KID | *Key Information Document* | Wettelijk verplichte samenvatting van een fonds, met kosten en risico-indicator (3.3) |
| MSCI | *Morgan Stanley Capital International* | Amerikaans bedrijf dat indexen maakt, zoals de MSCI World (3.3) |
| Nasdaq | *National Association of Securities Dealers Automated Quotations* | Amerikaanse beurs waar veel techbedrijven genoteerd staan; ook de naam van indexen als de Nasdaq-100 (bijlage module 3) |
| NV | Naamloze vennootschap | De rechtsvorm van de meeste beursgenoteerde bedrijven (3.1) |
| OCF | *Ongoing Charges Figure* | Lopende kosten van een fonds; in de praktijk vrijwel hetzelfde als de TER (3.3, 3.5) |
| S&P | *Standard & Poor's* | Amerikaans bedrijf achter onder meer de S&P 500 en kredietbeoordelingen (3.2, 3.3) |
| S&P 500 | *Standard & Poor's 500* | Index van de 500 grootste beursgenoteerde bedrijven in de Verenigde Staten (3.3) |
| SPIVA | *S&P Indices Versus Active* | Jaarlijks onderzoek dat actieve fondsen vergelijkt met hun index (3.3) |
| TER | *Total Expense Ratio* | De lopende kosten van een fonds per jaar, als percentage. Zit verwerkt in de koers (3.3, 3.5) |
| UCITS | *Undertakings for Collective Investment in Transferable Securities* | Europese regels voor fondsen, over spreiding, bewaring en informatie (3.3) |
| VS / VK | Verenigde Staten / Verenigd Koninkrijk | (3.3) |
| W-8BEN | Amerikaans belastingformulier | Zorgt dat er op Amerikaans dividend 15% in plaats van 30% wordt ingehouden; vul je in bij je broker (bijlage module 3) |

## Belangrijke begrippen

| Begrip | Betekenis |
| --- | --- |
| Aandeel | Een klein stukje eigendom van een bedrijf (3.1) |
| Assetallocatie | Hoe je je geld verdeelt over aandelen, obligaties en sparen (2.4) |
| Beleggingsplan (bij een broker) | Automatisch elke maand of week een vast bedrag beleggen; ook wel spaarplan (4.4) |
| Broker | De partij waar je beleggingen koopt en bewaart (4.1) |
| Buffer | Spaargeld voor onverwachte uitgaven, dat je nooit belegt (2.1) |
| Dividend | Het deel van de winst dat een bedrijf uitkeert aan aandeelhouders (1.1, 3.1) |
| EUR Hedged | Het valutarisico van een fonds is afgedekt naar de euro (bijlage module 3) |
| Factsheet | Een of twee pagina's met de belangrijkste gegevens van een fonds (3.3) |
| Fractioneel beleggen | Een deel van een aandeel of ETF kopen, zodat je hele bedrag belegd wordt (4.1) |
| Herbalanceren | Je verdeling terugzetten naar wat je in je plan hebt afgesproken (5.3) |
| Index | Een lijst met bedrijven die samen een markt weergeven, zoals de AEX of de MSCI World (3.3) |
| Introducing broker | Een broker die klanten binnenbrengt bij een grotere broker, zoals MEXEM bij Interactive Brokers (bijlage module 4) |
| Kernselectie | Bij DEGIRO: een lijst met ETF's die je goedkoper koopt (bijlage module 4) |
| Limietorder | Een order met een maximumprijs bij kopen (of minimumprijs bij verkopen) (4.3) |
| Marketorder | Een order die direct wordt uitgevoerd tegen de beste prijs op dat moment (4.3) |
| Notering | Een fonds of aandeel dat op een bepaalde beurs in een bepaalde valuta te koop is (bijlage module 3) |
| Obligatie | Een lening aan een overheid of bedrijf, waarvoor je rente krijgt (3.2) |
| Opkomende markten (*emerging markets*) | Landen waarvan de economie nog in ontwikkeling is, zoals China, India en Brazilië (3.3) |
| Rente-op-rente | Rendement dat zelf ook weer rendement oplevert (1.3) |
| Risicoprofiel | Hoeveel risico bij jou past: defensief, neutraal, offensief of zeer offensief (2.4) |
| Schijnspreiding | Meerdere fondsen die grotendeels dezelfde bedrijven bevatten (3.4) |
| Spread | Het verschil tussen de koop- en verkoopprijs op de beurs (3.5) |
| Ticker | Korte beurscode van een aandeel of fonds, zoals ASML of IWDA. Kan per beurs verschillen (3.1) |
| Tracking difference | Het verschil tussen het rendement van een fonds en dat van zijn index (3.3) |
| Volatiliteit | Hoe hard een belegging op en neer beweegt (3.4) |

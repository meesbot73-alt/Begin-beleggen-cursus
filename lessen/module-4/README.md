Na deze module:

- heb je een broker gekozen op basis van veiligheid, kosten en aanbod;
- heb je een beleggingsrekening geopend;
- heb je je eerste belegging gekocht;
- staat je maandelijkse inleg automatisch ingesteld.

> Deze module legt uit hoe je het zelf doet. Welke broker en welk fonds je kiest, is jouw beslissing. Het is geen persoonlijk advies.

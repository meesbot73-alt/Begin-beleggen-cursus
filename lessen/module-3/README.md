# Module 3: De basis van beleggen

In module 2 heb je bepaald hoeveel je belegt en hoeveel risico bij je past. In deze module leer je wát je straks koopt. Je leert aandelen, obligaties en ETF's kennen, je leest zelf een factsheet, je ziet hoe spreiding werkt en je rekent je eigen kosten uit.

Na deze module kun je:

- een aandelenpagina in een app lezen en begrijpen wat de belangrijkste getallen betekenen;
- uitleggen hoe obligaties werken en waarom ze rust in je portefeuille brengen;
- een ETF-factsheet lezen en ETF's vergelijken met een checklist;
- spreiding toepassen over bedrijven, sectoren, landen en tijd;
- je eigen totale beleggingskosten per jaar uitrekenen.

**Op YouTube:** video 01 (aandeel), 02 (ETF), 08 (index) en 09 (kosten) geven de korte uitleg. In deze module ga je een stap verder: je leert ermee werken.

> Alle voorbeelden in deze cursus zijn bedoeld als uitleg. Het is geen persoonlijk financieel advies. Genoemde indexen en fondssoorten zijn voorbeelden, geen koopadvies.

# Module 5: Een plan maken en volhouden

Je belegt nu. Het moeilijkste komt nog: het jarenlang volhouden, ook als de beurs daalt of als iedereen om je heen over een nieuwe hype praat. In deze module schrijf je je persoonlijke beleggingsplan, leer je de valkuilen in je eigen hoofd kennen en ontdek je hoe je je beleggingen bijhoudt zonder er elke dag naar te kijken.

Na deze module:

- heb je een beleggingsplan op papier, met regels voor als het tegenzit;
- herken je de denkfouten die beleggers het meeste geld kosten;
- weet je wanneer en hoe je herbalanceert;
- heb je een vast moment per jaar om alles na te lopen.
